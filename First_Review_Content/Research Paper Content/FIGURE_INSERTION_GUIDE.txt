Step 3: Optimize Images for Submission
──────────────────────────────────────
1. DPI: 300 pixels/inch (publication standard)
2. Format: PNG (supports lossless compression and transparency)
   Alternative: TIFF (if conference prefers; ensure LZW compression)
3. File size: Aim for 400–800 KB per image (not > 1 MB)
4. Quality check: Ensure all text labels are readable at final size

Convert using ImageMagick (command line):
  convert -density 300 -quality 95 input.png output_300dpi.png

Or in Python:
```python
from PIL import Image
img = Image.open('figures/Fig1_Boxplots.png')
img_resized = img.resize((int(img.width * 300/72), int(img.height * 300/72)))
img_resized.save('figures/Fig1_Boxplots_300dpi.png', dpi=(300, 300), quality=95)
```

Step 4: Insert into IEEE Paper (MS Word)
────────────────────────────────────────
1. Open the formatted IEEE paper in Word
2. Position cursor where figure should appear (right after describing results)
3. Insert > Pictures > From this device
4. Select PNG file (Fig8_ConfusionMatrices.png, etc.)
5. Right-click image > Wrap Text > Tight (for two-column layout)
6. Resize to fit single column width (~3.3")
7. Add caption: Right-click > Insert Caption > "Figure 8. [description]" (below image)
8. Update figure numbering if you reorder: Right-click > Update Field > Update entire table

Step 5: Cross-reference in Text
───────────────────────────────
In the paper text, add references like:

  "The confusionmatrices reveal (Fig. 8) that SVM's collapse on minority classes..."

Automatic cross-reference (Word):
1. Insert > Cross-reference
2. Reference type: Figure
3. Select the figure you want to reference
4. Choose format: "Figure [number]"

TECHNICAL NOTES FOR PAPER PRODUCTION:

1. Image Resolution:
   • Screen preview: 96 dpi (default)
   • Publication/PDF: 300 dpi minimum
   • Print (if hardcopy): 600 dpi recommended
   
2. Colour vs. Grayscale:
   • Most IEEE conferences accept colour in PDFs
   • If printing to paper, ensure plots remain readable in B/W
   • Heatmaps: Use colourmap that's colourblind-friendly (e.g., "viridis" in matplotlib)
   • Countplots: Use Set2 or husl palette (more distinguishable in grayscale)

3. Figure File Organization:
   Create this folder structure:
   LY Project Heart disease Prediction/
   ├── figures/
   │   ├── Fig1_Boxplots_300dpi.png
   │   ├── Fig7_EngineeredFeatures_300dpi.png
   │   ├── Fig8_ConfusionMatrices_300dpi.png
   │   ├── Fig9_ModelComparison_300dpi.png
   │   └── [other figures]
   ├── IEEE_Paper_CVD_Severity_Prediction.docx (final formatted version)
   ├── Heart_Disease_Complete.ipynb
   └── [other files]

4. Embedded vs. Linked:
   • Embedded: Image stored inside .docx file (file size larger, ~5–20 MB)
   • Linked: Image file separate, referenced by path (smaller .docx, but breaks if images move)
   • Recommendation: For submission, EMBED images into the .docx to ensure portability

5. Conversion to PDF:
   • Microsoft Word: File > Export as PDF (highest fidelity)
   • LaTeX/Overleaf: Compile to PDF directly (highest quality for scientific papers)
   • Check: Open resulting PDF in multiple readers (Adobe, Chrome, Foxit) to verify rendering
